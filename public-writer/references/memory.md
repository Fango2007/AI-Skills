# Public Writer Memory

Use this file as durable editorial memory for the user. Keep it concise, factual, and update it after each useful interview.

## Preferences

- Topics must stay broadly within AI in general unless the user explicitly expands scope.
- Prioritize meaningful LinkedIn post outlines over polished drafts.
- Default output language is English, but the skill should also support French posts and bilingual thinking.
- Avoid AI-slop, generic claims, and content that feels AI-generated.
- Interview the user deeply and challenge weak ideas before producing outlines.
- Use voice interview when the runtime supports it; otherwise use chat.

## Writing Style

- Starts from a concrete LinkedIn interaction, observation, resource, or example, then generalizes into a broader AI literacy point.
- Uses clear explanatory sequencing: context, definition of the concept, example, why it matters, practical recommendation, open question.
- Comfortable defining technical terms in accessible language, especially when translating English AI concepts into French phrasing.
- Uses quoted mini-dialogues or prompt examples to make abstract LLM behavior tangible.
- Blends educational content with personal reflection instead of pure opinion.
- Often ends with an open question to invite discussion, plus a personal PS for a speculative or more subjective angle.
- Can write in French, but the main intended output is English unless otherwise requested.

## Tone

- Pedagogical, precise, and accessible.
- Critical without being aggressive.
- Curious and reflective, especially around cultural or linguistic effects in AI behavior.
- Practical: points readers toward better usage, resources, or questions rather than just criticizing tools.
- Human and lightly conversational, with room for modest personal notes.

## Banned Or Risky Patterns

- Generic AI hype
- Generic LinkedIn motivational phrasing
- Unsupported claims
- Replacing the user's phrasing with polished but bland wording
- Over-smoothing the user's directness or critical stance

## Durable Ideas

- LLM sycophancy can be framed as "algorithmic flattery": models often validate user framing instead of challenging it.
- Better prompting is an AI literacy skill because LLMs have limits, biases, and side effects.
- A useful AI post can connect a visible model failure to the prompt/context that produced it, rather than only blaming the model.
- Possible recurring angle: English-heavy training data may influence interaction style, including positivity, consensus seeking, and validation.
